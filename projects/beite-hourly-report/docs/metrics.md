# 指标与展示规则

## 引力投放播报：下方了 / IAA

项目总行包含自然量，直接读取项目行；仅展示有消耗的项目及媒体，当天未出现或无投放的项目不造零行。自动发现项目和媒体，后台负责分组。媒体名称直接使用报表名称，不维护重复映射，不展开优化师。

默认：消耗 `平台_消耗`，激活成本 `标准激活成本`，首付成本 `标准_首日付费成本`，ROI `标准_首日付费ROI`。**本地不能自行重算替代这些原始成本 / ROI。** 校验可利用标准激活数、首日付费人数、首日金额检查响应一致性。

分组、项目、媒体分列；分组名与唯一项目名相同可合并；APP 逐个项目显示，增加 APP项目合计 / APP媒体合计，媒体列明确「合计」。项目分组聚合成本时从基础量加权，不能平均单行成本。

展示：表头蓝色、白字居中；内容水平垂直居中；深灰边框；项目浅色区分，合计行加粗；全盘单独标色。首付成本、ROI 是实心非渐变数据条，缺失保持缺失。截图不显示行号、列字母、网格线；表内包含业务日期和整点小时。不同项目保留各自最终模板，不把联合表的白底规则套到下方了。

IAA 指标可增减、设置数字 / 整数 / 百分比；消耗单位选择使用同一配置体系。普通引力表可选元、万、带小数万；联合小时报已改用千分位两位小数。

| J/K | 新增首日人均付费次数 / 金额 | 数数总表首日指标 |
| L | 总累计收入 | 历史24点收入 + 当天当前累计 |

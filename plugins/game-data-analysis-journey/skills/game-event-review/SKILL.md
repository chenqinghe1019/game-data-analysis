# 活动与商业化复盘

1. 确认规则、上线节点、资源投放、奖励与付费触点。将目标拆为参与、行为深度、进度、奖励、商业化、留存。分析从大盘到端、服、付费层、玩家生命周期和关键玩法。
2. 分析结论应回答变化量级、集中在哪些分组、观察数据能支持到哪一步及下一轮可复验的改动。多期活动用首发至今的相同相对日、同服和同市场。标注同期大盘、生命周期、投放与节假日配置变化。
3. 分开看曝光、参与、关键玩法行为、奖励领取、付费和活动后回访。流水拆付费人数、客单、商品价格、转化、触达频次；用资源产出、消耗与期末余额验证激励或门槛是否合理。输出“问题 → 动作 → 验收指标 → 已观察结果/待验证”。
4. 参照 [活动案例和计算](references/event-cases.md)。指标口径、日期对齐和 Excel 交付沿用通用工作流。

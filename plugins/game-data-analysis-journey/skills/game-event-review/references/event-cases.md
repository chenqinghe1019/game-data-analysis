# 活动案例与计算

## 多期活动趋势

例如七夕/情人节福利活动连续开三期。每期收集开放日历、开放服、入口和资格、全服 DAU、活动页参与、任务/关卡进度、奖励和付费配置、商品金额、下期或活动结束后的回访。按同进度日看趋势和累计，用 DAU 或符合资格人群计算渗透率，分开记录首发新鲜感、重复参与和大盘生命周期变化。

## 组队探索与战令

历史探索玩法为最多四人，小队消耗体力触发 PVP、PVE、奖励和选择事件，有积分成就、榜单与战令。曾有 328 元战令、固定特惠礼包和按 VIP 触发的体力礼包。历史一期三类收入份额为战令 19%、固定礼包 26%、触发礼包 55%。固定和触发同价档体力相同，触发礼包资源更集中；占比差需结合曝光覆盖、触发时点、复购、玩家分层及整期收入验证。分析免费体力和四人三天可达的战令档位、中奖或难度进度、队内贡献、体力缺口、积分与排行榜。任何商业化方案都配玩家收益、转化、购买结构与资源经济指标。

## 签到战令优惠券

历史方案为前三天卖 6 元膨胀券礼包（含 6 代币），可将 328 元战令降到 198 元。用签到账、券曝光、购券、看到优惠价、购战令、奖励领取的漏斗定位掉点。核心率提供“购券玩家中的战令转化”和“符合资格玩家中的整体战令转化”，再看券使用窗口、原价购买、实际净流水、完成率。方案改动以同期对照或分组验证。

## 抽奖期望

基础概率、分段起止、保底抽数做参数。若保底第 N 抽，令第 N 抽条件中奖概率为 1；无特殊机制时，首次抽到大奖的期望抽数为 `Σ[k=0 到 N−1] P(前 k 抽未中奖)`，其中 `P(前 0 抽未中奖)=1`，逐抽乘以前一抽的未中概率。核查概率在 0–100%、整型抽数、首尾包含、区间重叠、空档默认概率和保底位置。历史示例 1–200 抽 0.1%、201–299 抽 0.5%、第 300 抽保底。若保底计数继承或重置另有规则，先明确首次中奖还是多轮长期期望。

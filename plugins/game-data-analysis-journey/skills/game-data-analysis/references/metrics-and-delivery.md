# 指标与交付

| 指标 | 计算和核对 |
|---|---|
| DAU / 日均 DAU | 按日使用指定活跃事件及排重键统计；日均用完整日 DAU 的算术平均。周期去重活跃另列。 |
| 日均流水 | 窗口内流水 ÷ 实际有效天数，记录币种、实付/毛额、退款处理。 |
| 当日 ARPU | 当日收入 ÷ 当日活跃。日均 ARPU 可定义为每日 ARPU 的算术均值；如果采用 Σ日收入 ÷ ΣDAU，标为按活跃人日加权的日 ARPU。周期收入 ÷ 周期去重活跃另列。分母注明全服 DAU 或活动活跃。已指定看板口径时保留并注明来源。 |
| ARPPU / 付费率 | ARPPU 为同周期流水 ÷ 同周期去重付费人数；付费率为同口径付费人数 ÷ 活跃人数。标注按日、周期去重或按活跃人日加权。 |
| 广告渗透率 | 用户确认口径：当日观看广告的去重人数 ÷ 当日活跃人数。展示、完成、奖励到账事件区分；不同广告类型合计重算去重观看人数。 |
| 活动页参与率 / 人均参与次数 | 在保卫萝卜 4 案例中，用活动页活跃 ÷ 游戏 DAU、活动页启动次数 ÷ 活动页活跃。其他活动用已确认的参与事件和分母。 |
| 时长、次数和比率汇总 | 同定义的人均指标用其原分母做权重。人均时长按活跃人数加权，单次时长按次数加权；能取得原始总量时直接用总量 ÷ 总分母。 |
| 次日 / N 日累计回访 | 从指定活跃基准群体出发。次日为约定的相对日，累计为规定窗口内至少一次符合事件的人数 ÷ 基准人数。列明绝对日期、样本数和回访人数。 |
| 相对变化 / 比率差值 | 相对变化 = (后值 − 前值) ÷ 前值，前值为 0 留空并给绝对变化。汇报优先写「从 72.5% 降至 69.1%」。若需展示相对降幅或比率差值，分别注明含义。原分母为 0 的比率留空。 |

## Excel 和汇报

- 首个工作表放综合结论、核心指标、日期与口径。详表按问题组织，如前后对比、赛季对比、分端/区服、回访、商品、原始数据、映射表。用户给出图样时对齐表头、顺序和比较方式。
- 对比表列前值、后值、增减量、变化率；率类优先并列给出前后百分比，按需补充明确标注的差值或相对变化。明确金额或时长单位、完整日期、实际有效天数和数据来源。列名写全，保留原始 ID、原名和标准名的对应关系。
- 核对日历连续性、重复键、错误端、错选过滤、导出行数、金额与明细汇总、产品名称、Excel 公式错误、数值格式和文件可打开性。输出可下载的 xlsx，文件名包含主题与截止日期或日期区间。
- 总结适合运营汇报，优先用“整体变化 + 核心贡献组 + 关键例外”写成一段。按用户需要列完整分组，区分绝对流水增量、总流水占比和净增量贡献。生命周期衰退作为可能背景，用同服同生命周期、活动前趋势或同期对照进一步验证。

# AppLogger 来源与映射

| 数据 | 路径与口径 |
|---|---|
| 活动页、星途、主场景 | 页面分析：活动页 `scene_newcooperation_home`、星途 `scene_starway`、主页 `scene_main`。星途取 `scene_starway`，不要误取 `scene_summary`。 |
| 日活与参与 | DAU 可从页面分析导出。保留游戏 DAU、活动页新增、活动页活跃、启动次数；活动参与率用活动页活跃/游戏 DAU，人均参与次数用启动次数/活动页活跃。 |
| 关卡页面与事件 | 找 `cooperation_level` 系列对应页面与 `cooperation_levelxx_eventxx_xx` 事件。难度 1–5 按当期表映射，端点为航海新人和大航海家，中间名用原表核对。事件尾码 0 为失败，1/2 都计通关。按难度、关卡和端保存分项；通关率采用同口径结算事件数。 |
| 趋势 | 基本趋势、收入趋势按需求导出，分端和玩法保留日明细；报表同时记录数据源的筛选范围。 |
| 付费项 | 付费习惯中选计费点，记录原始键、原始名和合并名。含连字符的变体按同商品核对后合并；星途礼包依已核对尾号映射。历史计费点 `151230` 映射“空中花园限定装扮礼包”。不要靠相似文本合并未知商品。 |
| 消耗与产出 | 分产出和消耗拉取，统一道具 ID 与名称映射，按赛季同窗口对比。列日均、累计、净流入及口径。 |

S1 的实际赛季开启日和指定拿来比较的起算日可能不同。用户历史上指定过 S1 从 07-30 起取 20 天作为对照。保持实际开启日、对照起日、完整截止日分别可查。最新历史工作簿名为《保卫萝卜4_页面分析_20260709-20260819.xlsx》，具体分析窗口以工作表为准。

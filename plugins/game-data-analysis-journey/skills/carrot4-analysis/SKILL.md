# 保卫萝卜 4 双人合作分析

在 AppLogger 选择保卫萝卜 4 的安卓、鸿蒙、苹果（iOS），按端按日提取数据，保存原始导出后再汇总。按 [来源与映射](references/carrot4.md) 执行。

1. 按需从页面分析、页面事件、基本趋势、收入趋势、付费习惯和消耗与产出取数。确认实际选中端、目标页面、单日日期字段与起止时间。页面分析进入数据表格再下载。
2. 原始每日数据、前后 21 天、前后 20 天、S1/S2 同进度或截至某日的付费汇总可以并存。每张表用它自己的日期条件，表头标明前后窗口。历史 20 天对照是 2026-07-10 至 07-29 与 07-30 至 08-18，其他时期或赛季以当前确认日期为准。
3. 三端按日期对齐，先核对端别与行数，再合计 DAU、页面活跃、新增、启动次数及流水。按适用的原始分母汇总参与率、人均频次和时长。保留三端与总计、关卡事件、计费点、道具映射、原始数据和复算公式。
4. 发现安卓等单端为空时，先重查过滤状态、日期和真实导出，并在页面卡住后重进复核。确认的未上报零值按该历史口径保留，来源失效、字段缺失或未知状态另标。

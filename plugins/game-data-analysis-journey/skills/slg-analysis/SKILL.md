# SLG 上线与合服复盘

下方了（项目 41）先查仓库的 [SLG 活跃付费与回访口径](https://github.com/chenqinghe1019/game-data-analysis/blob/master/knowledge/projects/xiafangle/SLG_REVIEW.md)，再结合通用工作流与 [SLG 历史案例](references/slg.md)。

1. 对齐 TA 原看板、活跃付费报表、礼包明细和已验证 SQL。锁定分析对象（计划区服、实际进入 SLG 的区服、原始区服或合服组），记录区服范围、进入日和完整截止日。
2. 大盘同时看日均 DAU、付费率、日均流水、看板 ARPU、LTV 贡献、礼包购买率、礼包流水和礼包占比。整体大盘用整体报表，单品结构用礼包明细，先核对两侧差额。
3. 增补 VIP 回访，按进入前历史最高 VIP 固定分层，展示两期样本、实际回访人数、前后回访率、按需标明差值或相对变化和估算人数。清晰标记待观察窗口。
4. 拆出批次、合服小组及关键区服的绝对变化和贡献。排除指定区服、停服日或商品前，保存原始对照并明确每次过滤应用在哪个分子、分母和窗口；重新计算剩余组指标。
5. 结论按活跃、流水、回访同时评估，单列礼包能解释的账面变化、其他付费变化与需要对照验证的预算转移假设。

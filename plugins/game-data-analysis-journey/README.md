# 游戏数据分析之旅

这是 [游戏数据分析之旅插件](https://chatgpt.com/plugins/plugins_6b002af67c9881918c265648acae73b2) 的版本镜像，包含插件清单、五个分析技能及参考资料。

- 处理业务分析时，从 [项目工作规范](../../PROJECT_WORKING_RULES.md) 和 [Canonical 知识索引](../../knowledge/CANONICAL_INDEX.md) 进入。
- 用户确认的长期业务口径提交到 Canonical 或对应专题。插件已保存版本的改动另外同步到本目录。
- `sync-state.json` 记录最近同步版本和镜像内文件的 Git blob SHA，用于确认更新基线。

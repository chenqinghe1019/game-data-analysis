# 一耍就上头 IAA 游戏基础看板 SQL（2026-11-02）

项目：IAA_Game（54），game_name=yishuajiushangtou，正式用户domain=release；项目空间810。

本文件保存广告、关卡、在线时长九张已部署报表的完整 SQL。全套基础看板清单、公共身份/新增/活跃/留存口径及最新版规则见根目录 yishuajiushangtou_tracking.yaml。用户确认本项目为 IAA 游戏；不能将 IAA_Game 共用项目内其他游戏数据并入本游戏。未验证广告收入字段前不能用观看次数推导收入或广告LTV。

动态参数配置：

- PartDate:date1：统计日期，默认过去7天。
- PartDate:date2：注册日期，默认最近3651天；在用户注册范围映射$part_date后应用。
- Selector:selector3：渠道；全部渠道=1=1，3059310=channel_id='3059310'，未知=coalesce(nullif(channel_id,''),'未知')='未知'。新增渠道时维护选项。
- Selector:selector4：新老用户；全部用户=1=1，新用户=reg_day=date(day)，老用户=reg_day<date(day)。
- Variable5：四张广告报表为广告点名称；三张关卡报表为关卡名称；默认全部。
- Variable6：广告按关卡汇总/明细的关卡名称，默认全部，数值ID匹配。

展示：保存SQL图表表格并将看板卡片切换L19大图，维度在前、指标在后，比率数值0至1、显示2位百分数。

观看次数=count(ad_log)，完播次数=count_if(result='1')；观看结果记录不是开始曝光。每日分布保留0次活跃用户。时长用ta_mg_hide.#duration/60，无时长记录单列。失败汇总进入人数取同范围battle_start去重玩家。

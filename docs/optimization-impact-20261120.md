# 2026-11-20结构优化：影响与边界

| 改动 | 对使用的影响 | 对维护的影响 |
|---|---|---|
| 根README改为总导航 | 一个入口找到项目、知识、技能、插件与交接 | 旧文件路径和既有链接保留，过时的两技能/三技能示例移除 |
| 项目注册表 | 能区分同名、编号重叠、系统不同的资料 | 新项目先登记，生成可读索引；不替代后台项目配置 |
| 源文档到参考副本同步 | 安装包继续自包含，无需执行时连GitHub才能读参考 | 维护源只改一处；忘记生成时CI明确失败 |
| 确定性打包与版本清单 | 可比较内容指纹，判断拿到的包是否一致 | 内容不变时包不变，减少无意义二进制提交 |
| 构建和本机安装分开 | 旧package脚本默认不再覆盖本机技能，安装要加--install | CI可安全复用构建器；已安装技能不自动升级 |
| GitHub自动检查 | 提交后可看到注册、同步、链接、凭据与业务断言结果 | 检查失败需要修正后再依赖该版本；不自动发布、不自动推群 |
| 技能与插件职责对照 | 清楚7套Codex技能和5套插件技能的关系 | 插件仍是独立发布镜像，不承诺两边自动等价更新 |

## 生产影响

生产取数、指标公式、报表样式、调度顺序、已保存小时配置、Webhook、正式SQLite、Windows任务与后台端口均不改。没有部署或重启后台，没有拉业务数、补报或发送消息。

业务代码不搬迁，历史材料不删，公开仓库权限不改变。注册表里的项目状态是文档状态，不是实时启停状态；最近运行观察仍读带时间戳的runtime-status。

# 下方了 SLG 活跃付费与回访口径

## 数据来源和对比周期

- 从 [SLG留存表现](https://ta-data.feiyu.com/#/tga/ide/41_6255?fromPanel=41_2232) 返回「SLG活跃付费」看板，复拉「SLG整体表现」「SLG礼包购买」「SLG留存表现」。核对原 SQL 和筛选，商品配置调整后校验商品 ID 到名称和分类的映射。
- 大盘与礼包按批次核对前后实际起止日及可比天数，保留日均活跃、付费率、ARPU、日均流水、LTV 贡献、礼包流水和占比。ARPU 与 LTV 贡献沿用核实后的原报表公式，注明分母及周期。
- 历史对比首批为 1–146 服，2026-11-11 进入 SLG。第二批为 147–1236 服，2026-11-16 进入 SLG。后续批次及日期按当前看板或用户提供的上线配置确认。

## 回访率与 VIP 分层

- 正式环境 `domain = 'release'`，在 `ta.v_event_41` 用事件 `region_id` 分批、`$part_date` 划日，依据 `in_out_log` 判活跃，在同批内按 `#user_id` 去重。
- 上线前基准日取各批上线前 14 天的同星期，上线后取上线当天，两边各自构建基准日活跃玩家集。基准日记为 D1。D2 是次日，D2–D4 和 D2–D8 分别是次日起 3 天和 7 天。窗口内至少活跃一次的基准日玩家数 ÷ 对应基准日活跃人数，即该窗口的回访率。
- 对每名玩家，取所属批次进入 SLG 日期之前 `vip_change_log` 的 `before`、`after` 中出现过的最大有效 VIP 等级，前后共用该等级。没有有效历史记录归 V0。逐级明细可用于核查，汇报列全量和 V0–V3、V4–V6、V7–V9、V10+。各档分别汇总回访人数和基准人数，再计算比率。
- 截止取最近完整入库日，通常为昨日。窗口最后一天未完整入库时显示「待观察」，分母缺失或为 0 时单独标注。校验各档加总等于全量，同一基准日累计回访人数随窗口延长单调不减。

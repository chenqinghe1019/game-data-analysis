# 数据分析方法

effective_date: 2026-10-08

## 默认路径
指标异常
→ 核对口径
→ 拆人群
→ 拆生命周期/行为节点
→ 定位玩法/付费项/资源/战力
→ 做对照验证
→ 输出核心结论

## 拆分顺序
1. 总体：留存、LTV、付费率、ARPU、ARPPU、流水、关卡、战力。
2. 人群：免费/小R/中R/大R、首日R档、累计R档、VIP、渠道、平台、区服。
3. 节点：D2/D3/D7、关卡、系统开放日、活动周期、礼包、英雄、资源。
4. 结构：人数结构、行为转化、付费深度、内容承接。
5. 对照：版本前后、测试前后、强弱服、活动前后、不同 cohort。

## 输出
结论优先回答：
- 哪里变了
- 哪些人变了
- 在哪个节点变了
- 影响了什么

通常收敛到 3~4 个核心结论。异常值先核查，不直接归因。

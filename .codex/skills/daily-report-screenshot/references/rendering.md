# 渲染方式与验收

这是工作流说明，不包含预装渲染引擎或可直接调用的截图脚本。执行时先检查接收方实际可用的工具，不照搬作者机器的绝对路径。

## 现成工作簿渲染工具

环境提供电子表格渲染能力时，导入或创建工作簿，完成重算，保存 XLSX，渲染指定工作表与范围。验证导出文件与图片来自相同最终内容。复杂图表、条件格式和字体的兼容性需要实际检查。

## Windows Excel 原生导出

需接收方安装可用的 Microsoft Excel，且运行环境支持桌面自动化。打开工作簿副本，避免更新外部链接和运行宏，完成必要的公式重算；通过区域复制为图片再导出，或通过打印区域导出 PDF 后转 PNG。只关闭本次创建的工作簿与应用实例，不结束用户其他 Excel 进程。

## 办公软件转 PDF 再转 PNG

需接收方具备工作簿到 PDF 和 PDF 到图片的转换工具。设置打印区域、方向、页边距和缩放；宽度适配，长表按行分页并重复表头。生成后检查字体、分页及公式结果。注明为工作簿渲染图，不保证与 Microsoft Excel 像素完全一致。

## 完成判据

图片存在且可打开；表头、数字和中文不截断，无 `####` 或意外公式错误。图片包含所要求的全部范围，未包含无关工作表、个人资料和屏幕窗口。返回原尺寸文件；聊天缩略图过小时用户仍可打开查看。

不得使用图像生成模型补数字、伪造工作簿截图或把失败转换成旧文件成功。没有可用引擎时报告限制，不自动安装大型办公软件。

# 日报 Excel 与截图

交付同一份数据对应的 `report.xlsx`、一张或多张 PNG，以及简短预览说明。用户只要求现有 Excel 截图时，保留工作簿原样，不重做日报。

## 输入与范围

- 接受 XLSX、CSV、JSON、用户粘贴的表格；模板和截图范围可选。
- 先确认数据文件、数据日期、单位和目标区域。能从输入可靠识别的不要重复询问；关键口径缺失时询问，不猜测。
- 优先沿用用户模板。没有模板时采用简洁表格：标题与日期、核心指标、趋势或明细。只为实际提供的数据设置栏目。
- 本 Skill 不发送消息、不访问群机器人、不创建定时任务。用户另行要求发送时作为独立任务处理，不将截图请求视为发送授权。
- 不携带原作者的账号、路径、项目编号或业务数据。演示材料必须标注模拟数据。

## 生成

1. 检查列名、粒度、日期范围、重复键、空值、单位。保留源数据口径和筛选条件；汇总行不能与明细再次相加。
2. 输入为数数采集快照时，读取 [references/input-and-quality.md](references/input-and-quality.md) 的映射规则。不要依赖作者的浏览器或本地项目。
3. 在输出目录生成新的工作簿，避免覆盖输入。数字保持数值类型，日期和百分比使用单元格格式；标识符保留为文本。
4. 环比为 `(本期-上期)/上期`；上期为零或任一期缺失时显示不可比较。率的差值标明百分点，不能与相对变化率混用。不同成熟天数的 LTV、留存不直接比较。
5. 文字结论只引用可核对的数据，推测标注待验证。没有必要时不添加分析文案。

## 出图

根据运行环境选择可用的工作簿渲染工具，执行细则见 [references/rendering.md](references/rendering.md)。若环境有电子表格 Skill，遵循其工具使用和校验流程；没有时使用可用的工作簿读写、计算与渲染能力。

- PNG 应来自最终工作簿的指定工作表区域，并明确渲染工具。除非实际使用 Excel 原生截图，不声称是 Excel 原生截图。
- 不用生成式图像模型绘制表格数字。不把 HTML 重绘图冒充 Excel 截图；替代渲染方式必须说明并符合用户要求。
- 长表分为可阅读的多张图，重复表头，注明页序；不要为了单图容纳全部数据把字体缩到不可读。
- 无可用渲染器时明确缺少的能力，可交付已生成的 Excel，但不得声称截图完成。

## 校验与交付

核对关键数值与源数据；如有公式，重算并检查错误。打开每张 PNG 检查中文、标题、数字、换行、裁切和空白；检查图片对应最终保存版本。失败则修复后重新生成受影响产物。

交付 Excel 文件链接、直接可见的 PNG 预览和数据日期。历史数据标明历史预览，模拟数据标明模拟。说明未实际发送。仅报告已执行的验证，不将文档检查说成端到端运行成功。

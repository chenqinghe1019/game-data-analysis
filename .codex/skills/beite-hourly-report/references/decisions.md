## 典型故障与保留的教训

| 现象 | 应检查 / 防护 |
|---|---|
| 巨量首付成本从500多错成2000多、ROI不符 | 媒体原始首日指标是否错取优化师；不能混分母重算替代 |
| 微小抖小串数据、页面反复上下滚动 | 虚拟表不是静态DOM；用APPID/父节点/本次请求绑定校验，不依赖屏幕位置 |
| 查询卡网页加载、超时 | 本次查询完成及新鲜度；刷新重试，而非继续读旧缓存 |
| 某整点漏发 | 调度窗口、排序占用、任务保活、首报时间、slot状态、发送确认分阶段检查 |
| Excel占用 | 先确认SQLite是否已写入，关闭正式文件后重建，观察使用副本 |
| 历史小时ARPPU突然都有值 | 查来源与截止时间，不能把当前汇总倒填成历史分时 |
| 付费成本分母反复变更 | 最终用买量首日付费人数，16日底档不动，口径变更注明生效范围 |
| 第二天数据重复累计 | 累加每天24点和今天当前值，不能累加每小时累计 |
| 两图部分成功导致重发 | 每张图与文字分别记账，已确认成功跳过，结果未知暂停 |

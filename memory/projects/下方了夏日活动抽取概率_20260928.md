# 下方了｜夏日活动抽取概率口径（2026-09-28）

- 统计周期使用 `${PartDate:date2}`。
- 活动开服天数使用 `${Selector:selector2}`；夏日活动可填 `>=8`。
- 抽取行为：`item_log`，`item_name='能量电池'`，`change_type=2`。
- 每个玩家按能量电池累计消耗量，每10个划分一个区间：1-10、11-20、21-30……
- 某次抽取是否中大奖：从该次能量电池消耗事件时间开始，到下一次能量电池消耗事件时间之前，存在 `item_log` 获取 `item_name='夏日海滩'`、`change_reason=14817`、`change_type=1`。
- 人数大奖概率 = 大奖获取人数 / 抽取人数。
- 次数大奖概率 = 大奖获取次数 / 抽取次数；同一抽取窗口内即使出现多条大奖获取事件，只记1次中奖抽取。
- SQL：`sql/xiafangle/夏日活动_能量电池每10消耗_大奖概率.sql`。

- 修正：能量电池消耗事件的 `item_num` 可能为负数；抽取分桶需要按消耗量级转成正数后累计。筛选使用 `item_num <> 0`，单次消耗量使用负数取反、正数原值，避免原先 `item_num > 0` 导致结果为空。

- 2026-09-28更新：高累计消耗区间的“抽取次数”改为玩家累计抽取次数。玩家从首次抽取开始累计，直到首次获得 `夏日海滩`（`change_reason=14817`）为止；中奖后的后续抽取不再计入。玩家在每个到达的10电池区间内取截至该区间最后一次抽取的累计抽取次数，再按区间汇总；因此高区间的抽取次数包含此前区间的累计抽取。

- 2026-09-28确认：抽取次数不能按能量电池消耗事件条数计算，应按能量电池实际消耗数量计算；默认1个能量电池=1次抽奖。因此玩家累计消耗1-10个电池，对应累计抽奖次数为1-10次；若玩家在累计40个电池时首次获得夏日海滩，则该玩家累计抽奖次数记到40次并停止，后续不再计入。

# 下方了矿脉活动口径（2026-10-08）

- 项目：下方了（ta.v_event_41 / ta.v_user_41）。
- 矿脉活动按固定3日周期统计，但 S1/S2 必须分别独立识别周期，不能先全局编号再给玩家打赛季标签。
- 赛季来源：使用 in_out_log 的公共属性 season；season=1 输出 S1，season=2 输出 S2。
- 周期识别：先按 region_id + season 拆分矿脉发生日期；各自赛季内若相邻 mining_log 日期间隔 >3 天则视为新周期；周期号按 region_id + season 独立累计，因此 S1、S2 都从第1周期开始。
- mining_log 参与口径保持：任意 mining_log=矿脉参与；change_reason=1=占领参与；change_reason=3=掠夺参与。
- 新增每期活动深度指标：人均占领次数 = 周期内 change_reason=1 的 mining_log 总次数 / 占领参与人数；人均抢夺次数 = 周期内 change_reason=3 的 mining_log 总次数 / 掠夺参与人数。
- 两个人均次数均以对应行为参与人数为分母，不以活动活跃人数为分母。
- VIP 分层、活动付费人数/金额/ARPU/ARPPU 等原口径保持不变。

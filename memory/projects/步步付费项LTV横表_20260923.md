# 步步付费项LTV横表口径（2026-09-23）

- 项目固定使用 ta.v_user_22 / ta.v_event_22。
- 不依赖礼包配置表，不按一级/二级分类统计。
- 直接按 pay_log 的 product_id + product_name 作为付费项维度。
- 付费金额只取 payment，不使用 token_payment。
- payment 按步步现有口径 /100 转为元。
- 新增 cohort 按 create_role_time 自然日筛选；${PartDate:date} 只用于新增日期筛选，不作为结果分组维度。
- 新增天数使用条件型参数 ${Number:number6}，写法为 (days + 1) ${Number:number6}。
- 只统计成熟到昨天的数据：create_date + days <= current_date - 1。
- 输出 D1-D30 横表；每个 product_id + product_name 一行，并保留“汇总”行。
- Dn = 该付费项截至 Dn 的累计 payment 金额 / 已成熟到 Dn 的新增人数。
- 媒体平台从用户表 ad_platform 获取，空值按“自然量”，继续支持 ${Text:text} 筛选。

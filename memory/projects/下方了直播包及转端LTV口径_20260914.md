# 下方了直播包及转端 LTV 口径

更新时间：2026-09-14

## 统计对象

按 `nb_open_id` 作为唯一玩家，新增锚点统一取同一 `nb_open_id` 在 `ta.v_user_41` 全量角色中的最早 `create_role_time` 自然日。

当前该报表纳入两类玩家：

1. `直播包首次创角`：同一 `nb_open_id` 最早 `create_role_time` 对应 `channel_id = 3056219`（抖音直播投放包）。
2. `小程序转微端`：同一 `nb_open_id` 最早 `create_role_time` 对应 `channel_id = 3056211`（微信小游戏），且后续实际 `in_out_log` 行为渠道进入 `3056210 / 3056215 / 3056219` 中任一渠道。

`3056218` 主播直播体验包明确排除，不纳入该报表。

对于“小程序转微端”用户，目标微端渠道取其第一次进入上述端包行为渠道池时的实际 `channel_id`；渠道名称通过 `ta_ext.channel_id_41.channel_id -> channel_name` 关联。

## LTV

- 支付事件：`ta.v_event_41.pay_log`。
- 有效支付：`payment > 0`，不限制 `pay_result`、`change_reason`。
- 金额单位：`payment / 100` 转元。
- 同一 `nb_open_id` 的 LTV 汇总其全部角色、全部后续实际支付渠道的支付，不只统计目标微端渠道支付。
- LTV1 = 首次创角当天累计充值 / 新增人数。
- LTVn = 首次创角日起第 1～n 个自然日累计充值 / 新增人数，统计到 LTV30。
- 每个 LTVn 单独按成熟日期判断；观察截止统一为昨天。未成熟的 LTVn 返回 NULL。

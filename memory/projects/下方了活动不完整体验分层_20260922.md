# 下方了活动不完整体验分层口径（2026-09-22）

适用于按开服天数配置活动窗口、但统计期结束时部分新区服尚未完整体验活动的分析。

- 不再要求“活动理论结束日期 <= 统计结束日期”，因此纳入活动已开启但尚未完整体验的区服。
- 仍保留“活动理论开始日期 >= 统计开始日期”，避免把统计期开始前已经开启活动、左侧被截断的老服混入。
- 活动实际结束日期 = least(活动理论结束日期, 统计结束日期)。
- 活动体验天数 = date_diff('day', 活动理论开始日期, 活动实际结束日期) + 1。
- 按“活动体验天数”分组区服，例如完整6天、体验3天、2天、1天分别统计。
- 活跃、参与、活动付费均只统计该区服实际已体验的活动窗口。
- VIP层级仍取理论活动开始时间之前的最高VIP，不改为实际统计截止时间。
- 对应新增LTV基准同步按体验天数截断：若活动配置为D6-D11、区服仅体验3天，则新增基准使用D6-D8。
- 结果按“活动体验天数 + VIP层级”输出，并在每个体验天数下保留VIP汇总行。

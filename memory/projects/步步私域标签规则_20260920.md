# 步步私域标签规则（2026-09-20）

项目：步步 / 一步两步，固定使用 `ta.v_user_22` / `ta.v_event_22`，主体按 `#account_id` 汇总。

## 已确认迁移规则
- 活跃事件：`log_in_out`。
- 数据截止：所有事件数据统计到 SQL 执行当前时刻。
- 创角时间：`ta.v_user_22.create_role_time` 线上实际为 double Unix 秒，使用 `from_unixtime(try_cast(create_role_time as double))`。
- 付费：`pay_log.payment` 单位为分，金额统计前 `/100` 转元；仅统计正向 `payment>0`。
- 今天已付费：今天截至当前至少存在1笔正向 `pay_log.payment>0`，输出“是”，否则“否”；总表字段名为“步步_今天已付费”，放在“步步_0充用户”之后。
- 活跃任务成功日：事件 `task`，条件为 `task_type='QuestDaily'` 且 `change_reason=1`；一天完成11个才算成功一天。
- 消耗流失预警在线时长：使用 `log_in_out.online_time`，过滤 `online_time >= 86400` 的记录；按最近7日与前7日比较。
- 签到提醒：步步当前没有签到埋点，私域总表字段保留，但输出空值。
- 充值中断预警：沿用下方了私域规则——中断前连续10个自然日每天有正向充值，最近连续3个自然日充值为0则触发；当天重新充值后解除。
- 创角天数成就：累计达成 15/30/90/180/365/730，输出英文逗号分隔且不带“天”字，例如 `15,30,90`。
- “活跃任务完成”不单独作为输出标签，任务完成逻辑只用于“消耗流失预警”。

## 已确认补充
- VIP输出：按步步实际VIP等级输出，不再使用“贵族”归类；根据累计RMB充值金额对应 `VIP0`～`VIP16`，门槛沿用 `游戏项目/步步/配置/vip_level.yaml`。

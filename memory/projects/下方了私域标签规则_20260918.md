# 下方了私域标签规则（2026-09-18）

来源：用户于 2026-09-18 提供的标签规则截图及后续口径确认。项目固定使用 `ta.v_user_41` / `ta.v_event_41`，标签主体为 `#account_id`。

## 标签与业务规则

### 活跃与生命周期类
- 活跃情况：近7天登录天数 >=5 为高活；2~4天为中活；<=1天为低活。登录按 `in_out_log`。
- 近10日活跃：最后登录时间距今天数 <=10 为“是”，>10 为“否”；重新登录后恢复“是”。
- 企微新人（<=3天）：添加企微好友时间 <=3天，第4天自动移除。
- 0充用户：累计RMB付费金额=0；首次完成任意 >=1元充值后移除，同时打“付费破冰”。
- 付费破冰：添加企微时为0充，中途首次完成任意充值；里程碑性质，永久保留。

### VIP与付费类
- VIP等级：枚举 VIP0 / VIP1 / VIP2 / VIP3 / 贵族；当前游戏埋点可从 `vip_change_log.after` 取最新值。
- 当天高付费：当天总付费金额 >=1万元。
- 充值中断预警：连续3日充值金额为0；前提为“前10天每日有连续充值习惯”；当日有任意充值即移除。
- 消耗流失预警：
  - 活跃任务成功日：当天 `mission_finish_log.task_type=1` 且完成11个任务才算该日成功；实现时按当天 `mission_finish_log` 完成事件数 >=11 判断。
  - 一周内活跃任务成功天数 <=2天，或在线时长环比下降 >=50% 时触发。
  - 活跃任务成功天数恢复到 >=4天后次日扫描移除。
  - 本标签在线时长为专题例外：使用 `ta_mg_hide.#duration`，仅统计 `#duration < 86400` 的记录；不要套用项目其他流失专题的 `in_out_log.online_time` 口径。

### 流失与唤醒类
- 流失/沉睡：连续4天以上未登录；枚举按 4/7/14/21/31/61/91/121 天等层级，重新登录后即时移除。
- 近七日高付费：近7天总付费金额 >=3万元。
- 签到提醒：
  - 使用 `daily_sign_log.sign_name` 判断签到。
  - 当前有效 `sign_name`：`七日签到`、`福利签到`、`豪华签到`、`超值签到`。
  - 每天19点扫描；当天已签到则取消该标签。
- 企微活动提醒：用户连续3日未参与企微活动则提醒1次，一周最多提醒1次；连续10天未登录游戏则不再提醒。

### 事件与成就类
- 赛季成就：如 S1全英雄图鉴 / S1全皮肤收集等游戏内成就达成数据，永久保留。
- 创角天数成就：15/30/90/180/365/730天等里程碑，达到对应创角天数时于当日首次登录触发。
- 当前赛季：游戏内当前赛季数据（S1~S20），随赛季更新变化，历史赛季标签自动移除。
- 活跃任务完成：当天 `mission_finish_log.task_type=1`，完成事件数 >=11 才算“是”。
- 注册时间：创角/注册时间，使用 `create_role_time`。
- 私域默认角色：角色信息；当前截图未给出游戏内埋点来源。
- 已解绑角色：社区解绑全部游戏角色；当前截图未给出游戏内埋点来源。

## 当前埋点可用性

### 可直接由现有下方了埋点计算
- 活跃情况：`in_out_log`
- 近10日活跃：`latest_login_time` 或 `in_out_log`
- 0充用户：`total_payment_rmb` 或全历史 `pay_log`
- VIP等级：`vip_change_log.before/after`
- 当天高付费：`pay_log.payment/100`
- 充值中断预警：`pay_log.payment/100`
- 消耗流失预警：`mission_finish_log.task_type=1` + 每日11个任务成功口径；在线时长使用 `ta_mg_hide.#duration < 86400`
- 流失/沉睡：`latest_login_time` 或 `in_out_log`
- 近七日高付费：`pay_log.payment/100`
- 签到提醒：`daily_sign_log.sign_name`，枚举为七日签到/福利签到/豪华签到/超值签到
- 创角天数成就：`create_role_time` + `in_out_log`
- 当前赛季：公共事件属性 `season`，建议从最近 `in_out_log` 取
- 活跃任务完成：当天 `mission_finish_log.task_type=1` 且完成事件数 >=11
- 注册时间：`create_role_time`

- 已解绑角色：缺社区/私域侧角色解绑事件。
